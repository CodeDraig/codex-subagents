# Language Archive Preparation Kit

Use this record for the selected workflow. Adapt field names to a supplied schema without dropping source links, uncertainty, or version history. Keep the requested artifact format and workflow output contract.

## Working Record

- Collection/item ID, filename, role, format, version, and observed size/hash.
- Recording, transcript, annotation, excerpt, and replacement relationships.
- Participant role, variety, metadata source, and disclosure restriction.
- Agreement or decision ID, version, permitted use, and affected scope.
- Collection default, item exception, conflict, and decision owner.
- Destination validation and acceptance evidence, kept separate.
- Community-return derivative, source link, format, and permitted audience.

## Worked Example

The following is a synthetic example, not an observed collection, language, narrator, or site.

Recording R1 has transcript T1 and excerpt X1. Agreement A2 permits research-only use of one segment; the draft collection spreadsheet says public. The manifest retains R1→T1 and R1→X1 links, marks the conflict, and excludes the affected materials from a proposed public package pending an owner decision. A successful hash check does not resolve the access conflict.

## Failure Case

Copying a collection-wide public flag onto every file can expose an item exception or restricted metadata. Preserve the narrower scope as an unresolved or governing restriction according to the actual agreement; validate the proposed derivative package separately.
