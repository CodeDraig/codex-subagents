# Language Documentation Planning Kit

Use this record for the selected workflow. Adapt field names to a supplied schema without dropping source links, uncertainty, or version history. Keep the requested artifact format and workflow output contract.

## Working Record

- Project purpose, partner priorities, and source of each priority.
- Language or variety labels, identifiers, and naming decisions.
- Genre, context of use, participant role, and coverage gap.
- Session ID plan and expected recording/annotation outputs.
- Permission scope, agreement version, and access or reuse restrictions.
- Annotation and speaker-review capacity, owner, and dependency.
- Community return material, format, destination, and acceptance status.

## Worked Example

The following is a synthetic example, not an observed collection, language, narrator, or site.

A project seeks a family story collection and a small teaching wordlist. Existing material contains only elicited vocabulary. The plan adds story sessions as a gap, budgets transcript review, and proposes returning accessible audio copies. It records the teaching use as undecided because the existing agreement covers research analysis only.

## Failure Case

Calling a wordlist from one speaker a complete language dictionary overstates both scope and representation. Describe the actual source coverage, retain variety and speaker information, and name additional collection and review needs without inventing contributors.
