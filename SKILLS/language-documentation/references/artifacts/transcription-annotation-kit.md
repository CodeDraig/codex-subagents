# Linguistic Transcription And Annotation Kit

Use this record for the selected workflow. Adapt field names to a supplied schema without dropping source links, uncertainty, or version history. Keep the requested artifact format and workflow output contract.

## Working Record

- Segment ID, session, source file/version, and time or line anchor.
- Speaker label as supplied, variety, and access condition.
- Source form, transcript derivative, and uncertainty convention.
- Segmentation and token links to gloss or translation tiers.
- Attested evidence versus analytical proposal and alternatives.
- Normalization or editorial change, justification, and reviewer status.
- Format validation, audio inspection coverage, and unresolved span.

## Worked Example

The following is a synthetic example, not an observed collection, language, narrator, or site.

A supplied synthetic transcript has U1 "na ke" at 1.0–2.2 seconds. The supplied lexicon supports na = I and ke = walk. The annotation keeps the full source form, links each gloss to its token, and labels "I walk" as the supplied interpretation. U2 contains unlisted ku; its form remains ku and its meaning stays unresolved. Audio verification is recorded as unavailable.

## Failure Case

Changing ku to ke because it would make the sentence translatable corrupts attestation. Preserve ku, log the unresolved analysis, and request speaker or recording review rather than inventing a correction.
