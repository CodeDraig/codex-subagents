# Linguistic Session Design Kit

Use this record for the selected workflow. Adapt field names to a supplied schema without dropping source links, uncertainty, or version history. Keep the requested artifact format and workflow output contract.

## Working Record

- Session ID, question, genre, participant roles, and access scope.
- Prompt ID, motivating example, and hypothesis under examination.
- Prompt wording, task type, and optional follow-up.
- Response anchor, production type, and participant correction.
- Uncertainty, withheld answer, alternative form, or variety note.
- Recording and annotation requirements, review owner, and next step.

## Worked Example

The following is a synthetic example, not an observed collection, language, narrator, or site.

Two supplied utterances differ in a motion verb. Prompt P3 asks for a description of a pictured journey and links to both examples as the research motivation. A separate review prompt invites comment on the earlier recordings. The response sheet distinguishes spontaneous description from a judgment about a supplied sentence.

## Failure Case

A guide asks, "You use form X for all past events, correct?" and records expected answer yes. Replace it with contexts that permit other forms and an open review question; leave the response blank until actual evidence exists.
