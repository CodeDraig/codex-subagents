# Textual Witness Description: Working Kit

## Working Record

- Witness row: siglum | source ID | representation | attribution/date and basis | extent | access/inspection.
- Representation chain: original witness → image/edition → transcription/OCR, with version and responsible source.
- Overlap map: passage | witnesses covering it | gaps | location scheme.

## Worked Example

Packet contains scan A of a dated print and transcript B copied from an undated manuscript catalog entry. Register A as a scan representation of the print and B as a derivative transcript; record B’s manuscript date as unknown. Only lines 1–12 overlap, so the collation handoff is limited to those lines.

## Failure Case

Failure: call B the oldest witness because its filename says “original”, or infer paper/watermark features from its transcript. Correction: retain the filename as supplied metadata and separate unknown physical facts.
