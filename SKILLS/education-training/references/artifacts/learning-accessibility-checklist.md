# Learning Accessibility Checklist

Use these fields inside the selected workflow's output; they are not a separate response format.

## Record Fields

- Learner task and outcome.
- Artifact version and location.
- Access method inspected.
- Barrier and affected action.
- Proposed alternative.
- Construct preserved or changed.
- Verification method and status.
- Owner decision.

## Review Checks

- Do not mark untested keyboard operation as passed.
- Check whether captions identify speakers and meaningful non-speech sound.
- Separate an absent alternative from an alternative whose equivalence has not been tested.
