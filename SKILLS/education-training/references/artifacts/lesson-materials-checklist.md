# Lesson Materials Checklist

Use these fields inside the selected workflow's output; they are not a separate response format.

## Record Fields

- Segment start and duration.
- Outcome ID.
- Learner-visible instruction.
- Required input or material.
- Expected work product.
- Facilitator cue and common misconception.
- Answer or feedback location.
- Low-bandwidth or non-media alternative.

## Review Checks

- Instructions must work without hidden facilitator knowledge.
- Answer keys and learner handouts should not accidentally expose each other.
- A backup activity needs its own materials and timing.
