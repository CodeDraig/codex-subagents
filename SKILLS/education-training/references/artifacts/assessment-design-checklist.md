# Assessment Design Checklist

Use these fields inside the selected workflow's output; they are not a separate response format.

## Record Fields

- Item ID and outcome.
- Evidence demand.
- Stem and supplied inputs.
- Expected answer and rationale.
- Alternative acceptable response.
- Points and partial-credit rule.
- Estimated time.
- Rubric descriptor.
- Pilot or moderation status.

## Review Checks

- Weight totals must match the announced maximum.
- Avoid distractors that are wrong only through an unstated assumption.
- Separate proposed scoring from actual learner assessment records.
