# Source Synthesis and Outlining: Working Kit

## Working Record

- Source ledger: ID | creator/date/version | supplied location | source class | inspected extent.
- Outline unit: purpose | claim/scene | evidence IDs | counterargument/tension | transition | target length.
- Gap log: claim | missing support | effect on draft | next action.

## Worked Example

S1 is a dated council minute saying the reading room opened in May; S2 is a later memoir remembering an April opening. Outline section 2 distinguishes an informal opening from the recorded opening only as a hypothesis. The evidence map keeps S1 and S2 separate and assigns a date query instead of inventing an April ceremony.

## Failure Case

Failure: manufacture a vivid quotation from a paraphrased note. Correction: use attributed paraphrase, retain the note location, and request the original recording only if exact quotation is necessary.
