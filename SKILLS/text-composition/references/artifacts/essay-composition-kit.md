# Essay Composition: Working Kit

## Working Record

- Essay engine: question | concrete anchor | competing impulses | desired openness.
- Braid map: strand | appearance | new pressure/meaning | transition to next strand.
- Persona contract: supplied memory | invention permitted | source attribution | unresolved detail.

## Worked Example

Brief: a 600-word braided essay using supplied memories of repairing a radio and a factual note about static. Alternate repair scenes with the problem of interpreting noise. The final return to the radio changes what the narrator listens for, without pretending the radio repair proves a scientific or psychological thesis.

## Failure Case

Failure: invent the author’s deceased relative to give the ending emotional weight. Correction: develop significance from the supplied repair memory or explicitly propose an invented persona if the project allows one.
