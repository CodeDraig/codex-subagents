# Revision Planning: Working Kit

## Working Record

- Action record: issue/location | reader consequence | proposed action | preserved constraint | dependency | acceptance check.
- Priority categories: purpose-blocking; local repair; optional experiment; later polish.
- Coverage record: supplied units | inspected units | uninspected context | limits on conclusions.

## Worked Example

A report introduces “retention” in section 4 but relies on it in section 2. Plan: move the definition before its first use, then revise both transitions and check later references. This action precedes sentence polish in those sections and preserves the report’s unusual case-first opening.

## Failure Case

Failure: prescribe a new opening solely because the draft does not begin with a thesis. Correction: identify the actual orientation problem and propose the smallest change that serves the author’s chosen form.
