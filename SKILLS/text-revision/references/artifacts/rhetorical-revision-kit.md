# Rhetorical Revision: Working Kit

## Working Record

- Effect map: passage | intended effect | existing mechanism | revision | tradeoff.
- Meaning check: who/what | negation | certainty | causal claim | emotional stance.
- Protected language: refrains, dialect, intentional fragments, key images, named facts.

## Worked Example

Original: “We waited for the bell, and we waited for the door, and we waited for the name.” The brief asks for greater suspense while preserving the repeated openings. A revision changes the final object to a supplied concrete name and adjusts the pause before it; it keeps the accumulating “and we waited” rather than treating it as redundancy.

## Failure Case

Failure: make an uncertain finding sound definitive or insert an ornate metaphor that changes the narrator’s register. Correction: recover the original certainty and voice, then create emphasis through order, pace, or a supported image.
