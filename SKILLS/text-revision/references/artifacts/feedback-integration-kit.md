# Feedback Integration: Working Kit

## Working Record

- Feedback ledger: ID/source | current location | problem | proposed fix | decision/reason | revised location.
- Conflict record: competing changes | author goal/requirement | reversible work possible | unresolved choice.
- Closure check: every comment accounted for; actual text matches response; declined suggestions explained.

## Worked Example

Editor A asks to delete a recurring refrain; the author explicitly requires it. Editor B finds the surrounding explanation repetitive. Keep the refrain, shorten the explanation, record A as declined under the author constraint and B as accepted, and point both decisions to the revised passage.

## Failure Case

Failure: remove the refrain because two commenters requested it or mark all comments “done” after writing replies. Correction: use the author’s explicit priorities and inspect the actual revisions.
