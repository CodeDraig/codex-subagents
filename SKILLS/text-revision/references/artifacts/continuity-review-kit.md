# Manuscript Continuity Review: Working Kit

## Working Record

- Continuity row: entity/event | property | value | time/POV | source location | certainty.
- Conflict pair: location A | location B | incompatibility | context checked | repair dependencies.
- Knowledge map: character | information acquired | acquisition scene | later use.

## Worked Example

Chapter 1 states the bridge was destroyed on Tuesday; chapter 3, explicitly Wednesday with no rebuild, has a vehicle cross it. Report both passages and ask whether the crossing, date, or bridge identity should change. A character calling the bridge safe before learning of the destruction is a separate knowledge question, not the same contradiction.

## Failure Case

Failure: report an unresolved mystery as a dropped plot thread after reading only chapters 1–3. Correction: state the inspected extent and classify the later payoff as unverified.
