# Archaeological Finds Register Kit

Use this record for the selected workflow. Adapt field names to a supplied schema without dropping source links, uncertainty, or version history. Keep the requested artifact format and workflow output contract.

## Working Record

- Find or sample ID, parent ID, container, and original label.
- Site, context, recovery method, and provenance source.
- Material description as supplied, identification status, and specialist reference.
- Count, mass, or volume with units and counting method.
- Movement event, date, from/to custodian, and documentary support.
- Condition flag and conservation referral.
- Destination requirement, unresolved discrepancy, and acceptance status.

## Worked Example

The following is a synthetic example, not an observed collection, language, narrator, or site.

Field list F2 records bag B8 with five sherds from C12. A later analysis creates sample S8a from one sherd. The register keeps B8, S8a, and the parent link, records five original sherds, and marks the current remainder count unverified because the sampling report gives no return inventory. It does not silently change five to four.

## Failure Case

A spreadsheet reports twelve bags while a packing list reports twelve objects. Equal numbers do not reconcile different units. Keep both counts, map bag contents if evidence exists, and flag the missing object-to-container inventory.
