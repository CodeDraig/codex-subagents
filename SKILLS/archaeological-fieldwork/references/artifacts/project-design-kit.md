# Archaeological Project Design Kit

Use this record for the selected workflow. Adapt field names to a supplied schema without dropping source links, uncertainty, or version history. Keep the requested artifact format and workflow output contract.

## Working Record

- Question ID and supporting background source.
- Evidence needed, proposed method, coverage, and detection limit.
- Sampling rationale, exclusions, and bias.
- Record types, identifier scheme, and spatial reference.
- Access or intervention authorization, scope, and unresolved dependency.
- Specialist, conservation, analysis, and repository requirements.
- Alternative method, decision owner, and review point.

## Worked Example

The following is a synthetic example, not an observed collection, language, narrator, or site.

Question Q1 asks whether two recorded surfaces belong to the same phase. Survey S1 locates both but provides no stratigraphic link. The design proposes checking existing context records before considering a targeted intervention. Q1 remains unresolved if those records are missing. A separate line records archive acceptance as unconfirmed and identifies the project manager as the owner of that dependency.

## Failure Case

A brief says only the east half of a field was surveyed. Reporting the whole field as archaeologically empty fails coverage reasoning. Record the west half as unexamined, state the east survey method and limits, and retain further investigation as a proposal.
