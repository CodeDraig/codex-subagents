# Stratigraphic Sequence Review Kit

Use this record for the selected workflow. Adapt field names to a supplied schema without dropping source links, uncertainty, or version history. Keep the requested artifact format and workflow output contract.

## Working Record

- Context and relationship inventories with reviewed extent.
- Edge direction, relationship mapping, and excluded non-temporal relations.
- From/to contexts, source location, certainty, and proposed status.
- Cycle or conflict path and the source for every edge.
- Equivalence proposal and consequences of collapsing nodes.
- Supported ordering, unordered pairs, phase assumptions, and dating limits.

## Worked Example

With later-to-earlier edges C1→C2, C2→C3, and C3→C1, the review reports all three sheet references as a cycle. A separate C4→C5 chain remains usable. The result does not remove C3→C1 or infer that C1 and C3 are the same context. A sample dated in another report remains a dating claim until its context link is checked.

## Failure Case

A neat matrix produced by deleting the weakest-looking edge conceals the original contradiction. Report that edge as a candidate for source review, keep the conflicting records intact, and present any repaired ordering only as a labeled alternative.
