# Archaeological Field Recording Kit

Use this record for the selected workflow. Adapt field names to a supplied schema without dropping source links, uncertainty, or version history. Keep the requested artifact format and workflow output contract.

## Working Record

- Site, trench, context ID, original label, and source version.
- Observed description and separate interpretation.
- Relationship, other context, source anchor, and uncertainty.
- Coordinates, coordinate reference, units, precision, and measurement source.
- Plan, photograph, find, and sample identifiers.
- Observer, recorded date, transcription author, and revision note.
- Unresolved reference, collision, or restricted export field.
