# Oral History Project Planning Kit

Use this record for the selected workflow. Adapt field names to a supplied schema without dropping source links, uncertainty, or version history. Keep the requested artifact format and workflow output contract.

## Working Record

- Project question, historical scope, and source gap.
- Narrator selection criterion, relevant experience, and coverage limit.
- Proposed contact, participation status, and responsible owner.
- Recording, review, preservation, access, and reuse stages.
- Agreement scope, version, limits of promised control, and unresolved terms.
- Repository fit, return copies, resources, and dependencies.

## Worked Example

The following is a synthetic example, not an observed collection, language, narrator, or site.

A project about a closed ferry route has interviews from ticket staff but no passenger accounts. The plan names that perspective as a coverage gap, proposes selection criteria, and budgets narrator review. It does not list hypothetical passengers as recruited. The repository has not yet confirmed it can enforce a ten-year restriction, so deposit remains a dependency.

## Failure Case

A participant letter promises all online copies can be withdrawn forever. Replace the unsupported promise with the actual project-controlled withdrawal process and its limits; retain the unresolved terms for the project owner before the letter is used.
