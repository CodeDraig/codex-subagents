# Oral History Transcript Editing Kit

Use this record for the selected workflow. Adapt field names to a supplied schema without dropping source links, uncertainty, or version history. Keep the requested artifact format and workflow output contract.

## Working Record

- Interview ID, source version, speaker, and time or line anchor.
- Source wording and edited wording or linked derivative location.
- Punctuation/filler/dialect policy and reason for each substantive change.
- Uncertain hearing, editorial insertion, redaction, and later correction markers.
- Narrator review version, decision, and supporting record.
- Text/audio comparison coverage, unresolved query, and release status.

## Worked Example

The following is a synthetic example, not an observed collection, language, narrator, or site.

At 00:31 the supplied text reads, "I think it was May—no, June, maybe." A reading copy adjusts punctuation but retains both the self-correction and maybe. A later review note saying July is recorded as a narrator correction linked to that span, not substituted into the source transcript. With no recording supplied, audio verification stays unperformed.

## Failure Case

Changing "I did not see him leave" to "I saw him leave" while smoothing a false start reverses the account. Restore the negation, record the correction, and compare neighboring turns before accepting the edited passage.
