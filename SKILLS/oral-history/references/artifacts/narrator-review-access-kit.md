# Oral History Narrator Review And Access Kit

Use this record for the selected workflow. Adapt field names to a supplied schema without dropping source links, uncertainty, or version history. Keep the requested artifact format and workflow output contract.

## Working Record

- Interview, source/derivative version, segment, and requested use.
- Agreement or review decision ID, date, authority, and exact scope.
- Permitted audience, use, retention/deposit conditions, and time limits.
- Proposed package item and evidence of required review.
- Conflict, redaction gap, third-party disclosure, or missing decision.
- Supported disposition, unresolved owner question, and verification status.

## Worked Example

The following is a synthetic example, not an observed collection, language, narrator, or site.

Agreement A1 permits research access. A later email approves transcript V2 for a community booklet while withholding minutes 08–10. The proposed package contains V1 and the full recording. The review identifies the version mismatch and restricted interval, explains the bounded V2 permission, and leaves broader recording release unsupported.

## Failure Case

The project spreadsheet marks all items cleared because an email says "looks good." If the email identifies only V2, applying it to every derivative invents scope. Link the response to V2 and query the remaining package items.
