# Publication Proofreading

## Purpose

Compare a stable manuscript and its proof or final text to find production errors, missed corrections, and residual textual defects.

## Intake

Identify authoritative copy, proof/export version, prior correction list, house style, page/location scheme, permitted correction scope, and whether a corrected copy or correction list is requested.

## Workflow

1. Establish which file is copy and which is proof; confirm version and completeness before comparison. Keep proof-stage changes recoverable.
2. Compare text for dropped/duplicated words or lines, character substitutions, punctuation, headings, captions, notes, and approved corrections.
3. Inspect available rendered pages for line/page breaks, awkward splits, running heads, folios, tables, figures, notes, and spacing. Separate text extraction checks from actual visual inspection.
4. Record corrections by stable page/paragraph/line or anchor with existing text, replacement, category, and source or style basis. Apply changes only to the assigned working copy when requested.
5. Check correction implementation and affected neighboring text, then identify any changes that require reflow, reindexing, factual review, or another proof.

Read [proofreading-kit.md](../artifacts/proofreading-kit.md) when preparing the working record or checking the example against a similar request.

## Decision Rules

- Proofreading is not permission for a new developmental rewrite.
- A late textual correction may change pagination or locators; flag dependent checks.
- An intentional spelling or voice choice is not a typographical error merely because a checker flags it.
- An extracted-text comparison cannot establish that visual layout is sound.

## Verification

- Verify each correction against copy, house style, or explicit evidence.
- Check all supplied prior corrections and distinguish incorporated, missed, and superseded items.
- Record pages/units actually inspected and recheck changed text after applying corrections.

## Output Contract

Return exactly: `Proof Scope`, `Corrected Text Or Corrections`, `Prior Correction Status`, `Layout Observations`, `Recheck Needs`, `Coverage And Checks`, `Files Changed`, `Handoffs`.
Include supplied source or manuscript locations where relevant; distinguish applied changes, recommendations, unverified details, and coverage still outstanding. Put the requested text in the text section or identify the actual output file.

## Handoffs

Send layout/export issues to `publication-format-reviewer`, schedule/reflow dependencies to `production-editor`, locators to `indexing-coordinator`, and factual uncertainty to `fact-checking-editor`.

## Boundaries

Do not claim final publisher approval or inspection of unrendered/unseen pages. Keep the source manuscript unchanged unless it is the explicitly assigned correction target.
