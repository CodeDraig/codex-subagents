# Journal Submission Checklist

- Capture journal, article type, instructions date, submission stage, corresponding author, ORCID, deadline, and portal.
- Track manuscript file, title page, abstract, keywords, references, figures, tables, supplements, cover letter, highlights, graphical abstract, and data availability.
- Check reporting guidelines, ethics approval, consent, conflicts, funding, author contributions, permissions, and disclosure statements.
- For revisions, map each reviewer point to response, manuscript location, evidence, and unresolved author decision.
- Keep package preparation distinct from official submission and research integrity certification.

## Working Record

- Requirement matrix: instruction/version/location | component | status | evidence | owner question.
- Reviewer response: comment ID | issue | response text | actual manuscript change/location | evidence | unresolved decision.
- Package consistency: author/identifier | abstract/results | file versions | anonymity | disclosures | supplemental assets.

## Worked Example

Reviewer 2 requests a stronger causal conclusion, but the supplied observational study supports association. Draft a respectful response explaining the limit, point to the clarified discussion, and leave the underlying result unchanged. The package includes the requested cover letter and response text, not just a checklist.

## Failure Case

Failure: claim “additional experiments completed” without evidence or mark every response resolved before checking the manuscript. Correction: use the supplied results and verify each claimed revision.
