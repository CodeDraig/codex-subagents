# Indexing Workflows: Working Kit

## Working Record

- Entry record: heading/subheading | concept | source location | locator type | verified version.
- Reference audit: source heading | see/see-also target | target exists | useful relation.
- Reindex log: changed unit/page map | affected entries | correction | checked status.

## Worked Example

The manuscript has stable anchors but no final pages. Produce “memory, collective — ch2#collective; ch5#archive” and label these provisional electronic locators. A “remembrance. See memory” entry resolves to the actual memory heading; print pages remain pending.

## Failure Case

Failure: assign plausible pages from chapter length or index every mention of a name. Correction: use supplied locators and select passages that serve the reader’s index needs.
