# Edition Maintenance: Working Kit

## Working Record

- Change record: ID | old location/text | new text | category | evidence | edition/version | date if known.
- Artifact map: source/derivative | dependency | access/ownership | updated/generated | verified | pending.
- Public note: reader impact | correction wording | affected edition | unresolved distribution steps.

## Worked Example

A table label says 2018 but the supplied data and caption establish 2019. Correct the source label, check the caption and discussion, and mark the EPUB export as awaiting regeneration if only the Markdown source was supplied. The log identifies a factual label correction, not a claim that all distributed copies are fixed.

## Failure Case

Failure: announce “all editions updated” after editing one source file, or silently rewrite a conclusion as an erratum. Correction: enumerate actual artifacts and classify the substantive change honestly.
