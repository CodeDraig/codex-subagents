# Submission Package Preparation: Working Kit

## Working Record

- Requirement row: instruction/location | component | status | evidence | remaining action.
- Component record: filename/version | purpose | anonymity | word/page limit | source metadata.
- Factual check: biography; credentials; manuscript synopsis; prior publication; disclosures.

## Worked Example

A magazine requests an anonymous story and a separate 50-word biography. Prepare both from supplied author facts, remove the author name from the story header, and flag any embedded document metadata not yet inspected. The result is a package for review; no upload is claimed.

## Failure Case

Failure: invent an award in the cover letter or put identifying metadata into the anonymous manuscript. Correction: use verified author facts and check the actual anonymity surface, including metadata when tools permit.
