# Exhibit Interpretation Checklist

Use these fields inside the selected workflow's output; they are not a separate response format.

## Record Fields

- Label ID and object identifier.
- Label type and word budget.
- Core visitor question.
- Draft text.
- Claim-to-source location.
- Attribution or uncertainty qualifier.
- Image or audio description need.
- Sensitive interpretation and review owner.
- Copy version and approval status.

## Review Checks

- A label must not attribute an object to a named maker on stylistic resemblance alone.
- Accessible alternatives should explain relevant visual relationships, not just list colors.
- Keep object captions consistent with collection records or flag the discrepancy.
