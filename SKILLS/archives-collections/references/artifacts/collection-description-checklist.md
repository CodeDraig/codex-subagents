# Collection Description Checklist

Use these fields inside the selected workflow's output; they are not a separate response format.

## Record Fields

- Description level and identifier.
- Parent identifier.
- Source title and devised title.
- Creator attribution and evidence.
- Date expression and certainty.
- Extent with unit.
- Scope note and source location.
- Language or terminology decision.
- Restriction inheritance.
- Cross-reference target.

## Review Checks

- A series date range must not silently exclude child dates.
- Every cross-reference must resolve to a real or explicitly proposed record.
- Keep a proposed hierarchy distinguishable from existing storage arrangement.
