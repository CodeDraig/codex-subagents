# Accession Intake Checklist

Use these fields inside the selected workflow's output; they are not a separate response format.

## Record Fields

- Provisional intake ID.
- Container or file identifier.
- Extent and count unit.
- Creator versus donor versus custodian.
- Transfer document and date.
- Evidence-backed custody status.
- Observed condition and inspection limits.
- Restriction notice.
- Missing item or agreement.
- Accession owner decision.

## Review Checks

- One box and one folder are different count units; preserve both.
- Match attachments to the signed agreement version where available.
- Do not convert a temporary deposit into an accession through a filename or status label.
