# Production Planning Checklist

Use these fields inside the selected workflow's output; they are not a separate response format.

## Record Fields

- Deliverable ID and audience.
- Communication outcome.
- Runtime and format source.
- Language, captions, transcript, and versions.
- Source asset dependency.
- Script, recording, edit, review, delivery dates.
- Resource assumption and confirmation owner.
- Budget basis if supplied.
- Contingency and approval status.

## Review Checks

- Every derivative or language version needs edit and review time.
- Do not mark a permission request as cleared.
- Flag dependencies whose latest feasible date already precedes the planning date.
