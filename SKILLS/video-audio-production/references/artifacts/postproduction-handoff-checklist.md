# Postproduction Handoff Checklist

Use these fields inside the selected workflow's output; they are not a separate response format.

## Record Fields

- Asset ID and original path.
- Original, proxy, derivative, or placeholder.
- File size, duration, and available identity evidence.
- Source timebase and sync reference.
- Script segment or edit range.
- Project and cut version.
- Rights or restriction status.
- Offline or missing dependency.
- Review-note owner and resolution.
- Destination handoff status.

## Review Checks

- Record both source and timeline timecodes when they differ.
- Do not resolve duplicate basenames by silently choosing the first file.
- A placeholder must remain visibly identified in the review handoff.
