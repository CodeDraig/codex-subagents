# Asset Review

Full manual content review of all 36 affected workflow/kit pairs, five gateway routers and UI metadata, and 32 new or modified agents. Scores assess reusable instructions, not guaranteed model behavior. All seven criteria are explicitly scored per mode and agent. Static parsing and live evidence are recorded separately.

Scores are in the criterion order below; each digit is a score out of four. A minimum of three is required. Runtime-fit scores are design judgments; representative runs do not benchmark every role or model.
