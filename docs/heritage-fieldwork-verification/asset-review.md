# Heritage and Fieldwork Asset Review

Complete manual instruction-quality review of 21 agents, 21 workflow/kit pairs, four gateway routers, and four sidecars (71 files). Each pair was walked through against its worked example and failure case: 42 static walkthroughs. These are judgments about instructions and artifacts, not live outcomes, independent review, or professional certification.

Every required criterion is at least 3/4. Supporting-asset scores remain 3 because the kits provide adaptable record fields and examples rather than destination-specific production schemas. Agent instruction-depth scores remain 3 because their fallback is intentionally condensed; the selected workflow contains the full procedure. No required fixes remain from this manual pass.

Skill score order: trigger/routing, workflow, heuristics, supporting assets, tooling/validation, output, boundaries. Agent score order: distinctness, skill/reference use, depth, runtime fit, handoffs/boundaries, output, integration. Scores, source hashes, and per-asset evidence are retained in [asset-review.json](asset-review.json).
